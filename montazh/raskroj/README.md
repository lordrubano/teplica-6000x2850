# Раскрой поликарбоната — крыша, стены, фронтоны, окна

Материалы для монтажников: раскрой 6 листов сотового поликарбоната KIN PREMIUM 6 мм (2100×6000) на теплице 6000×2850. Часть 1 — крыша, листы А, Б, В. Часть 2 — стены, фронтоны, окна, листы Г, Д, Е.

## Ссылки для монтажников

- Анимация всех 20 шагов (открывается в браузере телефона):
  https://lordrubano.github.io/teplica-6000x2850/montazh/raskroj/
- Инструкция для печати (карта раскроя, чертежи, шаги, фотоотчёт):
  https://lordrubano.github.io/teplica-6000x2850/montazh/raskroj/instrukciya-raskroj.pdf
- Ролик MP4 (можно пересылать в мессенджере):
  https://lordrubano.github.io/teplica-6000x2850/montazh/raskroj/rolik-raskroj.mp4

## Что в папке

- `index.html` — страница с анимацией.
- `rolik-raskroj.mp4` — ролик всех шагов, около 170 секунд, 1280×720, можно пересылать в мессенджере.
- `instrukciya-raskroj.pdf` — инструкция, 16 страниц A4.
- `src/animaciya.html` — исходник анимации: шаги, размеры, тексты.
- `src/instrukciya.html` — макет инструкции.
- `src/sborka.js` — сборка: страница анимации, кадры шагов, PDF.
- `src/rolik.js` — запись ролика из анимации.
- `zadanie.md` — техзадание, по которому сделан комплект.

Тексты шагов в PDF берутся из анимации, поэтому они всегда совпадают.

## Главные размеры

- Лист: 2100×6000, соты вдоль длины, около 16,4 кг. Листы А, Б, В — крыша, Г, Д, Е — стены, фронтоны, окна. Сейчас развёрнуты 3 листа, остальные 3 — в рулонах.
- Кровельный кусок: соты вдоль ската, кромка в 10 мм от оси стропила, между листами 20 мм. Нижний торец — вровень с нижним концом направляющей. Длина L — по примерке конькового профиля, не больше 1800.
- Ширина куска = замер − 20 мм. Ожидаемо, у конька / у карниза: Л1 1485/1490, Л2 1455/1455, Л3 1452/1460, Л4 1475/1475, П1 1485/1483, П2 1455/1450, П3 1452/1455, П4 1475/1485. Окончательно — по 16 замерам после установки направляющих.
- Деталей 34: крыша 8, полосы крайних стропил 4, стены 8, части фронтонов 6, створки окон 8 (400×1545). Плюс полоса 2100×600 для контроля веса (около 1,6 кг, меньше 1,4 кг — стоп).
- Запасы: лист В — остаток не меньше 2100×2400, лист Е — около 2100×2000.

## Пересборка

Нужны Node.js, Playwright с Chromium и пакет `qrcode`.

```
cd src
node sborka.js
node rolik.js
```

Для ролика нужен ffmpeg с кодеком libx264 (путь — в переменной `FFMPEG`). Если сеть к CDN закрыта, библиотеку three.js r128 и шрифты можно подставить из папок `THREE_DIR` и `FONTS_DIR`; промежуточные файлы — в `OUT_TMP`.
