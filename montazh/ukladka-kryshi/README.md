# Крыша: раскрой и укладка листов

Материалы для монтажников: раскрой трёх листов сотового поликарбоната KIN PREMIUM 6 мм (А, Б, В) на 8 кровельных кусков и укладка их на крышу теплицы 6000×2850. Работа только снизу, изнутри, с лестницы: бруски ставятся по пролётам вместе с листами. Стены, фронтоны и окна сюда не входят — они в инструкции по раскрою, часть 2.

## Что в папке

- `index.html` — страница с анимацией (две сцены: площадка раскроя и каркас теплицы).
- `rolik-ukladka.mp4` — ролик всех шагов, около 5 минут, 1280×720, около 9 МБ, можно пересылать в мессенджере.
- `instrukciya-ukladka.pdf` — инструкция, 22 страницы A4.
- `src/animaciya.html` — исходник анимации: шаги, размеры, тексты.
- `src/instrukciya.html` — макет инструкции.
- `src/sborka.js` — сборка: страница анимации, кадры шагов, PDF.
- `src/rolik.js` — запись ролика из анимации.
- `zadanie.md` — техзадание, по которому сделан комплект.

Тексты шагов в PDF берутся из анимации, поэтому они всегда совпадают.

## Главные правила

- Работать только снизу. На крышу и на лист не вставать; человек на стремянке перегибается через стропило по пояс, под пояс на стропило — мягкая подкладка.
- Бруски — по пролётам: бруски пролёта, лист Л, лист П, только потом следующий пролёт. Порядок по умолчанию 2 → 3 → 1 → 4; можно 1 → 2 → 3 → 4; нельзя сначала оба крайних.
- Крышки на средних стропилах (пары 2, 3, 4) — заранее, лист задвигается в пазы снизу; крайние (пары 1 и 5) — с открытых фронтонов вместе с полосами.
- Длину листа даёт пробный кусок 1455×600 в пазах: L = А − 3, не больше 1800.
- Оси брусков от нижнего торца листа: 324 · 604 · 884 · 1164 · 1444 мм. Отверстия: круглое 7 мм на 884, на остальных овал 7×12 вдоль ската. Термошайба без ножки + жёлтый саморез Pz 4×50.
- Верхнюю плёнку снимать сразу после задвигания, до термошайб.
- Запасные способы: шаг 22 (класть сверху, крышки потом) и шаг 23 (лаз у конька).

## Пересборка

Нужны Node.js, Playwright с Chromium и пакет `qrcode`.

```
cd src
node sborka.js
node rolik.js
```

Для ролика нужен ffmpeg с кодеком libx264 (путь — в переменной `FFMPEG`). Если сеть к CDN закрыта, библиотеку three.js r128 и шрифты можно подставить из папок `THREE_DIR` и `FONTS_DIR`; промежуточные файлы — в `OUT_TMP`, адрес готового ролика — в `OUT_FILE`.
